## 问题摘要

在将 OC 项目 (cag2-ios-west) 迁移到 Swift 项目 (cag3-west) 时，gRPC/Protobuf 网络层出现多个编译错误。

## 根因分析

| 问题 | 根因 | 影响 |
|------|------|------|
| IOS-001 | 在 pb.swift 基础上手写 `Services.grpc.swift` 封装层 | 类型不匹配、协议冲突 |
| IOS-002 | 用 `JSONEncoder` 处理 `SwiftProtobuf.Message` | 编译错误：不符合 Codable |
| IOS-003 | pbxproj 手动编辑时遗漏 Sources build phase | 运行时找不到类型 |
| IOS-004 | 假设属性名而非查看生成代码 | 属性访问错误 |

## 解决方案

### 1. 简洁 APIClient 模式

```swift
class APIClient {
    func call<Req: SwiftProtobuf.Message, Res: SwiftProtobuf.Message>(
        service: String, method: String, request: Req
    ) async throws -> Res {
        var urlRequest = URLRequest(url: URL(string: "\(baseURL)/\(service)/\(method)")!)
        urlRequest.httpMethod = "POST"
        urlRequest.httpBody = try request.jsonUTF8Data()  // ✅ 正确方式
        let (data, _) = try await URLSession.shared.data(for: urlRequest)
        return try Res(jsonUTF8Data: data)  // ✅ 正确方式
    }
}
```

### 2. 直接使用生成类型

```swift
// ✅ 正确：直接使用 Cag2_xxx 类型

self.recommendations = response.data.map { WorkModel(from: $0) }
```
